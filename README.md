# Сферум.Ассистент

Встраиваемый цифровой ассистент для автоматизации рутины учителя и организации учебного процесса внутри экосистемы **Сферум (платформа MAX)**.

Проект разработан в рамках **Всероссийского хакатона «Идея фикс»** (трек *«Арсенал мастера»*, номинация *«Продвинутая разработка»*).

---

## 🎯 Проблема и решение

- **Проблема учителя:** классные руководители тратят часы на разрозненные сообщения в чатах: родители присылают фотографии справок в личные переписки, заявления на кружки теряются, а составление регулярных отчетов для завуча и школьного медпункта превращается в рутину.
- **Решение «Сферум.Ассистент»:** единое цифровое окно внутри Сферума. Ученики и родители подают справки об отсутствии и записываются в кружки за 1 минуту, а классный руководитель видит структурированный реестр своего класса, проверяет документы в один клик и выгружает сводки.

---

## 🚀 Ключевые возможности

1. **Авторизация и ролевая модель:**
   - Четкое разделение на роли: **Учитель (классный руководитель)** и **Ученик/Родитель**.
   - Связка по классам: классный руководитель видит справки и данные исключительно учеников своего класса.

2. **Модуль справок и отсутствий:**
   - Подача заявлений и справок с указанием дат и причины (по болезни / по семейным обстоятельствам).
   - Прикрепление подтверждающих медицинских документов.
   - Верификация учителем: статусы *«На рассмотрении»*, *«Принята»*, *«Отклонена»* (с причиной отказа).

3. **Модуль кружков и секций (Допобразование):**
   - Каталог школьных кружков с расписанием, преподавателем и лимитом свободных мест.
   - Электронная подача заявки от ученика/родителя.
   - Управление набором и утверждение кандидатов руководителем кружка.

4. **Интерфейс и пользовательский опыт (UX):**
   - Стильный дизайн с плавными переходами и эффектом матового стекла (Liquid Glass).
   - Прелоадер с **3D-кристаллами** (сине-голубая палитра Сферума), защищающий от белого экрана при переходах.
   - Полная адаптивность под мобильный экран внутри мессенджера MAX и десктопные браузеры.

5. **Безопасность:**
   - Хэширование паролей пользователей (SHA-256 с солью).
   - Готовность к валидации сессии MAX Bridge по алгоритму `HMAC-SHA256` (`initData`).

## 🚀 Инструкция по запуску

### Вариант 1. Запуск через Docker (рекомендуемый)

1. **Сборка контейнера:**
   ```bash
   docker build -t spherum-assistant .
   ```

2. **Запуск сервиса:**
   ```bash
   docker run -d -p 8000:8000 --name spherum-assistant spherum-assistant
   ```

3. Откройте в браузере: **http://localhost:8000/auth.html**

---

### Вариант 2. Локальный запуск (без Docker)

1. **Создание и активация виртуального окружения:**
   ```bash
   # Windows PowerShell
   python -m venv venv
   .\venv\Scripts\activate

   # Linux / macOS
   python3 -m venv venv
   source venv/bin/activate
   ```

2. **Установка зависимостей:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запуск веб-сервера:**
   ```bash
   python -m uvicorn app.main:app --reload --port 8000
   ```

4. Откройте страницу авторизации: **http://localhost:8000/auth.html**

## ⚙️ Настройка интеграции с MAX

Для боевого режима работы в экосистеме Сферума укажите токен вашего бота в переменной окружения:

```bash
# Linux / macOS
export MAX_BOT_TOKEN="ваш_токен_бота"

# Windows CMD
set MAX_BOT_TOKEN=ваш_токен_бота

# Windows PowerShell
$env:MAX_BOT_TOKEN="ваш_токен_бота"
```
