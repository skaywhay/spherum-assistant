# 🎓 Сферум.Ассистент

Веб-сервис для автоматизации документооборота и мониторинга внеурочной деятельности в экосистеме **Сферум**. Сервис централизует сбор медицинских справок, заявлений об отсутствии и учёт охвата дополнительным образованием учащихся.

> Проект разработан в рамках **Всероссийского хакатона «Идея фикс»** (трек *«Арсенал мастера»*, номинация *«Продвинутая разработка»*).

---

## 🎯 Проблема и решение

- **Проблема учителя:** классные руководители тратят часы на хаос в мессенджерах: фотографии справок приходят в личные сообщения, заявления на кружки теряются, а к концу месяца приходится вручную сводить для завуча ведомость посещаемости и отчёт по охвату внеурочкой.
- **Решение «Сферум.Ассистент»:** единая цифровая среда. Ученики подают справки об отсутствии и записываются в кружки в несколько кликов с формированием электронных бланков, а классный руководитель получает оперативный журнал класса на 28 человек, мониторинг занятости и возможность принимать/отклонять документы с фиксацией причин.

## 🚀 Ключевые возможности

### 1. 🌐 Глубокая интеграция с экосистемой VK / Сферум
- **VK Bridge SDK (`@vkontakte/vk-bridge`):** при запуске приложения вызывается нативная инициализация `vkBridge.send('VKWebAppInit')`. Сервис органично адаптируется под контейнер VK Mini App.
- **Запуск в формате VK Mini App:** автоматическое распознавание параметров запуска (`vk_user_id`, `sign`, `vk_app_id`).
- **Криптографическая верификация подписи:** бэкенд проверяет валидность строки запуска по алгоритму HMAC-SHA256 с использованием секретного ключа приложения.
- **Подтягивание профиля из образовательного аккаунта:** при авторизации через VK Mini App данные обучающегося синхронизируются с учебным реестром школы.

### 2. 📄 Серверная генерация официальных документов (PDF с печатью и ЭЦП)
- **Формирование бланков государственного образца:** серверный рендеринг PDF-документов по утверждённой Минздравом РФ **Форме № 095/у** (на базе `reportlab` с поддержкой кириллических TrueType-шрифтов).
- **Официальная синяя печать:** круглая гербовая печать медицинского учреждения («ГБУЗ ДГП № 38 ДЗМ • Для справок»).
- **Штамп квалифицированной электронной подписи (УКЭП):** визуальный штамп с серийным номером сертификата, владельцем (главный врач) и сроком действия в соответствии с ГОСТ Р 34.10-2012.
- **Динамический QR-код верификации:** каждый документ снабжён QR-кодом со ссылкой на онлайн-реестр подлинности (`/api/verify-doc/{id}`). При сканировании камерой смартфона открывается официальная страница подтверждения подлинности. Для жюри это признак готового к промышленному внедрению продукта!

### 3. 📱 Оптимизация под мобильные устройства (Mobile First & Bottom Sheets)
- **Адаптивные шторки (Bottom Sheets):** все модальные окна (просмотр документов, подача справок, запись на кружки, отказ, список класса, панель жюри) на экранах смартфонов шириной 360–400px автоматически трансформируются в нативные мобильные шторки с закруглёнными верхними углами, мобильным drag-handle и плавной анимацией slide-up.
- **Безопасная прокрутка таблиц:** таблицы списка класса, охвата внеурочной деятельностью и реестров кружков обёрнуты в контейнеры `overflow-x-auto` с минимальной шириной, что гарантирует удобный горизонтальный свайп без поломки вёрстки страницы.
- **Тач-карточки:** на мобильных устройствах список заявлений и обращений переключается в карточный режим с крупными кнопками действий.

### 4. 👩‍🏫 Кабинет классного руководителя
- **Интерактивные счётчики (KPI):** оперативный контроль справок на проверке, принятых документов, охвата внеурочной деятельностью и состава класса.
- **Журнал посещаемости на 28 учащихся:** мониторинг статуса присутствия каждого ученика на текущий учебный день («Присутствует», «Справка принята», «На проверке»).
- **Проверка электронных сканов:** просмотр аутентичных бланков документов, согласование в 1 клик либо отклонение с выбором официальной причины.
- **Ведомость внеурочной занятости класса (Отчёт завучу):** расчёт реального процента охвата класса дополнительным образованием, список кружков каждого ученика и статус зачисления.
- **Управление своей секцией:** учитель как педагог дополнительного образования может вести свой кружок, подтверждать заявки и контролировать заполняемость мест.
- **Автообновление данных (Live):** справки и заявки от учеников появляются у учителя автоматически в реальном времени каждые 3.5 секунды.

### 5. 🎒 Кабинет учащегося
- **Электронная подача справки:** выбор причины отсутствия, удобный выбор дат через календарь и генерация подтверждающего бланка.
- **Мои кружки и недельное расписание:** наглядные карточки кружков со статусом («Зачислен в группу» / «На проверке»), контактами педагога, аудиторией и возможностью отозвать заявку.
- **Сводный график занятости:** визуальная сетка недели (Пн–Пт) с указанием времени и кабинетов.
- **Общешкольный каталог секций:** выбор кружков с индикацией свободных мест и подачей заявления.

### 6. ⚡ Панель жюри и интерактивная песочница (Sandbox Mode)
Плавающий пульт в левом нижнем углу интерфейса для демонстрации работы системы экспертам:
- **Генерация событий:** создание входящей справки от случайного ученика из 28 человек класса либо заявки в кружок в 1 клик.
- **Авто-поток обращений (45 сек):** фоновый таймер, имитирующий непрерывную жизнь школы во время презентации.
- **Моментальное переключение профиля:** мгновенный переход между учителями и учениками без повторного ввода паролей.
- **Просмотр эталонного PDF и QR:** ссылки на генерацию официального бланка 095/у и проверку в онлайн-реестре.
- **Сброс базы данных:** возврат к исходному состоянию конкурса одной кнопкой.

## 🛠 Стек технологий

- **Frontend:** React 19, TypeScript (Strict Mode, 100% без `any`), `@vkontakte/vk-bridge` (интеграция с платформой VK Mini Apps), Tailwind CSS v4, Vite, Lucide Icons.
- **Backend:** Python 3.11+, FastAPI (0.115+), ReportLab (генерация PDF по форме 095/у), QRCode & Pillow (генерация QR-кодов верификации), SQLite (легковесная БД без внешних СУБД), Pydantic v2 (2.10+), Uvicorn (0.30+), python-dotenv.
- **DevOps:** Docker (Multi-stage build Node 20 + Python 3.11-slim с кириллическими шрифтами `fonts-dejavu-core`, Healthcheck, `.dockerignore`), запуск в 1 клик (`run.bat`, `run.py`).
- **Zero-Dependency Serving:** продакшн-бандл скомпилирован в `frontend/dist/` и раздаётся напрямую через FastAPI — проверяющим **не требуется** устанавливать Node.js или npm.

## 🔒 Архитектура информационной безопасности (Security & Hardening)

В проекте реализована комплексная эшелонированная защита (Defense-in-Depth) без привлечения тяжёлых сторонних библиотек:

1. **🛡 Защита от SQL-инъекций (SQLi):**
   - 100% запросов к базе данных SQLite используют строгие параметризованные плейсхолдеры (`?`).
   - Исключена конкатенация строк и интерполяция пользовательского ввода в SQL-выражения.

2. **🚫 Санитизация и фильтрация XSS / Эксплойтов:**
   - Все текстовые поля (Ф.И.О., класс, причины справок, названия секций) проходят глубокую очистку в [`app/security.py`](app/security.py).
   - Вырезаются вредоносные теги `<script>`, инъекции обработчиков событий `onload=`, `onerror=`, псевдо-протоколы `javascript:`, `vbscript:`, `data:text/html`, теги `<iframe>` и `<embed>`.
   - Применяется полное экранирование HTML-сущностей (`html.escape(quote=True)`) и удаление непечатных управляющих символов и байтов.

3. **🔐 Криптостойкое хэширование паролей (PBKDF2-HMAC-SHA256):**
   - Пароли пользователей защищены алгоритмом **PBKDF2** с хэш-функцией **SHA256**, **100 000 итераций** и криптографически стойкой 16-байтовой солью (`secrets.token_bytes`).
   - Проверка хэша выполняется через функцию постоянного времени `hmac.compare_digest`, исключающую **тайминг-атаки** (timing attacks).

4. **🎟 Подписанные крипто-токены и ролевой доступ (RBAC):**
   - При авторизации выдаются токены с криптографической подписью **HMAC-SHA256** на основе серверного секретного ключа (`SPHERUM_SECRET_KEY`) и временной метки истечения (TTL).
   - Эндпоинты согласования документов (`PATCH /api/absences/{id}/status`), создания кружков и ведомостей защищены инъекцией зависимостей FastAPI `require_teacher`. Попытки изменения данных учеником пресекаются кодом **HTTP 403 Forbidden**.

5. **⏱ Защита от перебора паролей (Brute-force) и DoS:**
   - Встроен высокопроизводительный скользящий лимитер (In-Memory Sliding-Window Rate Limiter).
   - Эндпоинты входа и регистрации ограничены **15 запросами в минуту** на IP-адрес. При превышении сервер отдаёт **HTTP 429 Too Many Requests** со стандартным заголовком `Retry-After`.
   - Общий лимит на API предотвращает спам-скрипты и исчерпание пула соединений.

6. **📦 Защита от переполнения буфера (Payload Size Limit):**
   - Запросы к серверу с размером тела свыше **1 МБ** отсекаются на уровне middleware с кодом **HTTP 413 Payload Too Large**, предотвращая DoS через исчерпание оперативной памяти.

7. **🌐 Заголовки безопасности браузера (Security Headers Middleware):**
   - `Content-Security-Policy (CSP)` — строгая политика источников ресурсов (скрипты, стили, шрифты).
   - `X-Content-Type-Options: nosniff` — защита от MIME-sniffing эксплойтов.
   - `X-Frame-Options: SAMEORIGIN` — защита от Clickjacking.
   - `X-XSS-Protection: 1; mode=block` — встроенный XSS-фильтр браузеров.
   - `Referrer-Policy: strict-origin-when-cross-origin` — защита от утечки чувствительных рефереров.
   - `Permissions-Policy: camera=(), microphone=(), geolocation=()` — изоляция аппаратных API устройства.

> 💡 **Запуск теста безопасности:** убедиться в корректности всех рубежей защиты можно командой:
> ```bash
> python tests/test_security.py
> ```

## 🚀 Инструкция по запуску

### Вариант 1. Запуск в 1 клик (Windows, без Node.js)

Просто дважды кликните по файлу **`run.bat`** в корне проекта:
```cmd
run.bat
```
Скрипт автоматически запустит сервер на **http://localhost:8000/**.

---

### Вариант 2. Запуск через Python (Windows / Linux / macOS)

1. **Создайте и активируйте виртуальное окружение:**
   ```bash
   # Windows PowerShell
   python -m venv venv
   .\venv\Scripts\activate

   # Linux / macOS
   python3 -m venv venv
   source venv/bin/activate
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите сервис:**
   ```bash
   python run.py
   # Либо напрямую:
   python -m uvicorn app.main:app --reload --port 8000
   ```
   > 📱 `run.py` выведет две ссылки: для ПК (`http://localhost:8000`) и для мобильного телефона в локальной сети Wi-Fi (`http://192.168.0.x:8000`).

---

### Вариант 3. Запуск через Docker (Multi-Stage Build)

1. **Сборка образа:**
   ```bash
   docker build -t spherum-assistant .
   ```

2. **Запуск контейнера:**
   ```bash
   docker run -d -p 8000:8000 --name spherum-assistant spherum-assistant
   ```

3. Откройте в браузере: **http://localhost:8000/**

---

### Вариант 4. Режим активной разработки фронтенда (Hot Reload)

Если вы хотите вносить изменения в интерфейс с мгновенной горячей перезагрузкой:
```bash
npm run dev
# Откроется Vite dev-сервер: http://localhost:5173/ с проксированием API на :8000
```
Для сборки продакшн-бандла:
```bash
npm run build
```
