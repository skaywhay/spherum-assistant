# Сферум.Ассистент

Встраиваемый цифровой ассистент для автоматизации рутины учителя и организации учебного процесса внутри экосистемы Сферум (платформа MAX).

Проект разработан в рамках Всероссийского хакатона «Идея фикс» (трек «Арсенал мастера», номинация «Продвинутая разработка»).

---

## Возможности сервиса

- Управление дедлайнами: создание карточек заданий со сроками сдачи.
- Шеринг в один клик: нативная отправка заданий напрямую в чаты классов через MAX Bridge (shareMaxContent).
- Реестр справок и посещаемости: учёт отсутствующих учеников и статуса медицинских справок.
- Интерфейс Liquid Glass: адаптивный дизайн с эффектом матового стекла, оптимизированный под мобильные и десктопные устройства.
- Безопасность: проверка целостности сессии пользователя по алгоритму HMAC-SHA256 (initData).

---

## Стек технологий

- Backend: Python 3.11, FastAPI, SQLite
- Frontend: HTML5, CSS3 (Liquid Glass UI), JavaScript, MAX Bridge API
- DevOps: Docker

## Инструкция по запуску

### Вариант 1. Запуск через Docker (рекомендуемый)

1. Сборка контейнера:
docker build -t spherum-assistant .

2. Запуск сервиса:
docker run -d -p 8000:8000 --name spherum-assistant spherum-assistant

Сервис будет доступен по адресу: http://localhost:8000

---

### Вариант 2. Локальный запуск (без Docker)

1. Создание и активация виртуального окружения (по желанию):
python -m venv venv
venv\Scripts\activate      # Для Windows
source venv/bin/activate   # Для Linux/macOS

2. Установка зависимостей:
pip install -r requirements.txt

3. Запуск веб-сервера:
python -m uvicorn app.main:app --reload --port 8000

## Настройка интеграции с MAX

Для работы валидации сессии в боевом режиме укажите токен вашего бота в переменной окружения:

export MAX_BOT_TOKEN="ваш_токен_бота"   # Linux / macOS
set MAX_BOT_TOKEN=ваш_токен_бота       # Windows CMD
$env:MAX_BOT_TOKEN="ваш_токен_бота"    # Windows PowerShell
