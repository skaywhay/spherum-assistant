# Сферум.Ассистент

Веб-сервис для автоматизации рутины учителей и классных руководителей в экосистеме **Сферум**. Сервис централизует сбор медицинских справок, заявлений об отсутствии и заявок в школьные кружки и секции.

Проект разработан в рамках **Всероссийского хакатона «Идея фикс»** (трек *«Арсенал мастера»*, номинация *«Продвинутая разработка»*).

---

## 🎯 Проблема и решение

- **Проблема учителя:** классные руководители ежедневно тратят часы на обработку хаотичных сообщений в чатах: родители присылают фото справок в личные диалоги, заявления на кружки теряются, а к концу месяца приходится вручную сводить данные для завуча и школьного медпункта.
- **Решение «Сферум.Ассистент»:** единая система учета. Ученики подают справки об отсутствии и записываются в кружки в несколько кликов, а классный руководитель видит структурированный журнал своего класса, проверяет документы и управляет набором в секции.

---

## 🚀 Ключевые возможности

1. **Авторизация и ролевая модель:**
   - Четкое разделение на роли: **Учитель (классный руководитель)** и **Ученик**.
   - Связка по классам: классный руководитель имеет доступ к данным только своего класса (например, 9-А видит только 9-А, 10-Б — только 10-Б).

2. **Модуль справок и отсутствий:**
   - Подача заявлений с указанием периода отсутствия и причины (по болезни / по семейным обстоятельствам).
   - Прикрепление подтверждающих медицинских документов.
   - Проверка учителем: статусы *«На рассмотрении»*, *«Принята»*, *«Отклонена»* (с указанием причины).

3. **Модуль кружков и секций (Допобразование):**
   - Каталог секций с расписанием, преподавателем и лимитом свободных мест.
   - Электронная подача заявки от ученика.
   - Управление списком группы и подтверждение заявок руководителем.

4. **Интерфейс и пользовательский опыт (UX):**
   - Минималистичный, интуитивный интерфейс в фирменной палитре Сферума.
   - Прелоадер с 3D-анимацией кристаллов, исключающий эффект белого экрана при переходах.
   - Полная адаптивность под любые устройства (смартфоны, планшеты, десктоп).

5. **Безопасность:**
   - Безопасное хранение учетных данных пользователей с хэшированием паролей (SHA-256 с солью).

## 🚀 Инструкция по запуску

### Вариант 1. Запуск через Docker (рекомендуемый)

1. **Сборка контейнера:**
   ```bash
   docker build -t spherum-assistant .
   ```

2. **Запуск сервиса:**
   ```bash
   docker run -d -p 8000:8000 --name spherum-assistant spherum-assistant
   ```

3. Откройте в браузере: **http://localhost:8000/auth.html**

---

### Вариант 2. Локальный запуск (без Docker)

1. **Создание и активация виртуального окружения:**
   ```bash
   # Windows PowerShell
   python -m venv venv
   .\venv\Scripts\activate

   # Linux / macOS
   python3 -m venv venv
   source venv/bin/activate
   ```

2. **Установка зависимостей:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запуск веб-сервера:**
   ```bash
   python -m uvicorn app.main:app --reload --port 8000
   ```

4. Откройте страницу авторизации: **http://localhost:8000/auth.html**
